# ReadEasy (瑞典语电子书阅读器)

专为阅读瑞典语书籍与 PDF 文档打造的桌面电子书阅读软件，提供类似 Kindle / Apple Books 的沉浸式阅读体验，内置划词即查中文字典与双语左右分栏对照模式。

---

## 🌟 核心功能

1. **电子书阅读器体验**
   - **多种排版模式**：
     - **双文对照模式 (Bilingual Mode)**：左边是瑞典语原著，右边是流畅通顺的中文翻译。段落左右对应，鼠标悬停时两边联动高亮，对照极其舒适。
     - **纯瑞典文模式 (Single Mode)**：沉浸式阅读排版，段落缩进与精美排版，专为瑞典语精读设计。
     - **原版扫描模式 (Scan & OCR Overlay)**：查看原书扫描版图像，叠加隐形 OCR 选词层，可在扫描页面上直接划词查词。
   - **舒适阅读主题**：
     - 📜 **羊皮纸 (Sepia)**：温润暖色护眼底色，保护视力。
     - ☀️ **日间白 (Light)**：清晰明亮标准模式。
     - 🌙 **夜间黑 (Dark)**：深色护眼暗黑模式。
   - **字号无级调节**：支持从 14px 到 28px 自由放大与缩小字号。
   - **章节导航与目录**：自动提取全书章节（Prolog、Marcus 1963、Iris、Hanna 等）。
   - **全书搜索**：一键搜索书中任何单词或短句，点击搜索结果立即跳转对应页码。

2. **自动记忆上次阅读位置**
   - 每次关闭软件前，自动保存当前阅读页码、滚动偏移行数、阅读模式（双文/单文/扫描）、字号与主题配色。
   - 下次打开软件，**无缝回到上次关闭时的确切位置**，无需手动翻页。

3. **划词查词小浮窗 (选词即查，不选即隐)**
   - **智能词形还原 (Lemmatization)**：支持瑞典语复杂的屈折变化自动还原原形，例如：
     - 动词过去式：`svarade` 自动识别原形 `svara`
     - 名词定指形式：`stolen` 自动识别 `stol`
     - 名词复数形式：`känslor` 自动识别 `känsla`
     - 各种不规则动词：`mindes -> minnas`、`såg -> se`、`gick -> gå`、`kom -> komma`
   - **中文字典释义**：即时显示精确中文释义与词性标注。
   - **双语发音与英文参考**：内置 Folkets Lexikon 音标与 Web Speech 原生瑞典语音频朗读（点击 🔊 即可听发音）。
   - **自动隐藏**：鼠标选中单词即刻弹出浮窗，鼠标点击空白处或取消选中文本，浮窗**自动平滑消失**。
   - **生词本 (⭐ 记生词)**：可在查词小窗中一键将生词加入生词本，方便随时复习与导出。

4. **快捷键支持**
   - `←` / `PageUp`：翻到上一页
   - `→` / `PageDown` / `Space`：翻到下一页
   - `Ctrl + B`：展开 / 收起侧边栏

## 🚀 启动与使用方式

### 方式一：直接双击运行 exe（推荐）
直接在当前目录双击：
- `启动ReadEasy.bat` 或 `ReadEasy.vbs`
或者打开 `dist\ReadEasy\` 文件夹直接运行：
- `dist\ReadEasy\ReadEasy.exe`

### 方式二：Python 源码运行（开发模式）
```bash
python main.py
```

## 📁 目录结构说明

- `dist/ReadEasy/ReadEasy.exe`：打包完成的独立 Windows 应用程序
- `启动ReadEasy.bat`：根目录一键启动脚本
- `ReadEasy.vbs`：根目录静默无弹窗启动脚本
- `Änglarnas svar.pdf`：当前阅读的瑞典语书籍文档
- `data/`：
  - `book_ocr.json`：全书 OCR 文本与词框坐标数据
  - `book_processed.json`：结构化去连字符段落数据
  - `translations_cache.json`：段落中文翻译缓存
  - `folkets_lexikon.json`：瑞典语官方词典数据（36,000+ 词条及音标）
  - `dict_cache.json`：本地词典查询缓存
  - `vocab.json`：用户生词本数据
- `web/`：现代化前端阅读器（HTML5 + CSS3 + 现代 JavaScript）
- `server.py`：后端嵌入式微服务（提供页面排版、翻译同步与词典查询）
- `dictionary.py`：瑞典语智能词形还原与本地/在线多级词典引擎
- `main.py`：桌面原生 WebView2 启动器
